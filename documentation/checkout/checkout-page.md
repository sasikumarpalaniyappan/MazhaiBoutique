# Checkout Page Documentation

## Purpose
The checkout page handles order placement and customer delivery information.

## Key Features
- Customer form collection
- Order summary display
- Order saving to local storage
- Optional EmailJS email sending
- Redirect to order success page

## Main Components
- Checkout form UI
- Cart summary display
- Order confirmation handling

## Notes
This page is implemented in app/checkout/page.tsx and is a critical part of the customer purchase journey.
